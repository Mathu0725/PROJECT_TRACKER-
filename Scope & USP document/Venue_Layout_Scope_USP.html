PROJECT OVERVIEW

Complete 2D venue setup foundation

A centralized 2D configuration platform used to create, verify, customize and manage venue/stadium inventory. Phase 1 covers block creation, measurement handling, AI verification, correction, General Admission, seating, table plans and multiple parking layouts.

Phase 1 — Functional Scope
01

2D Block Creation

  • Create venue blocks manually on a 2D canvas.
  • Upload a venue blueprint and auto-create blocks.
  • Use measurements from the blueprint when available.
  • If required, use one known real measurement as the scale reference, then update the real measurement and recalculate all related blocks automatically.
02

AI Verification & Accuracy

  • Compare created blocks against the uploaded blueprint.
  • Check whether all expected blocks exist.
  • Validate block shape and block naming accuracy.
  • Display an overall accuracy score.
  • List blocks that require correction.
03

Block Correction

  • Trace Mode: select a target blueprint block to recreate it.
  • Dot Mode: create a block by placing points on the blueprint.
  • Re-run AI refinement to improve the verified result.
04

Block Customization

  • Classify a created block according to its intended inventory use.
  • Support General Admission, Seating Plan and Table Plan configurations.
  • Reuse the same created 2D block geometry as the configuration foundation.
05

General Admission

  • Select an existing 2D block.
  • Keep the previously defined block dimensions.
  • Set the block type to General Admission.
  • Configure permitted capacity / allocation count.
  • Save the block as a ready-to-use GA area.
06

Seating Configuration

  • Manual seating creation and seat-by-seat placement.
  • Arrange seats by rows and support auto seat creation.
  • Support curved seating and aisle creation.
  • Autofill using seat width, seat length, gaps, row gaps, aisle sizes and other measurements.
  • Apply autofill configuration to multiple blocks with deselection control.
  • Upload Excel seating-plan data.
  • Reuse saved seating configurations for similar blocks.
07

Table Plan Configuration

  • Select a dining/hospitality block.
  • Create and arrange tables or add tables one by one.
  • Place and lock fixed areas first: stage, food preparation, entrance and other fixed elements.
  • Define table sizes, waiter-way width, wall gaps and spacing rules.
  • Generate table-count and layout-pattern suggestions.
  • Dynamically update possible table count when measurements change.
  • Select a preferred suggestion and save the plan.
08

Parking Layouts

  • Attach multiple parking layouts to a single stadium.
  • Create parking areas and slots manually.
  • Upload a parking image and auto-create the layout.
  • Support bike, car and EV parking slot types.
  • Save parking area and slots as stadium parking inventory.
09

Optimo SCS Tix Backend, Database & Authentication

  • Use the existing Optimo SCS Tix database structure wherever applicable.
  • Reuse existing Optimo SCS Tix backend endpoints / APIs as the primary integration layer.
  • Add new tables, fields, relationships or endpoints only where required.
  • Keep additions compatible with the existing Optimo SCS Tix architecture and data model.
  • Use the existing Optimo SCS Tix authentication and access-control mechanism.
  • Operate as an extension of the existing Optimo SCS Tix ecosystem.

CORE USP

Blueprint to verified operational venue inventory.

A single venue setup platform that transforms venue blueprints and real-world measurements into verified, reusable, operational 2D inventory — with AI-assisted accuracy checking and dedicated configuration workflows for seating, General Admission, hospitality tables and parking.

Product Differentiators (USP)
01

Blueprint-to-Inventory in One Application

Instead of using separate drawing, validation, seating, table-plan and parking tools, the application keeps the entire setup lifecycle in one platform.

02

AI-Assisted Accuracy Verification

The solution compares created geometry with the uploaded blueprint, identifies missing or incorrect blocks, validates shape/name accuracy and reports an overall accuracy score.

03

Measurement-Aware Layout Creation

Real measurements are part of the model. A known dimension can establish scale, and a corrected real-world measurement can update related blocks consistently.

04

Human + AI Correction Workflow

Trace Mode, Dot Mode and repeated AI refinement provide controlled ways to fix missing or inaccurate blocks without relying only on automation.

05

Smart Table Plan Optimization

The table-plan workflow considers fixed areas, table dimensions, waiter ways, wall gaps and spacing rules, then suggests feasible table counts and layout patterns that update dynamically.

06

Multi-Layout Parking Support

A single stadium can maintain multiple parking layouts. Parking can be designed manually or auto-created from an uploaded image, with inventory support for bike, car and EV spaces.

07

Reusable Configuration Model

Configured seating and other layout settings can be reused for similar blocks, reducing repeated setup work and improving consistency across large venues.

USP Positioning Statement

“For venue and stadium operators who need to create reliable bookable inventory, the Venue Layout Setup Application provides a unified 2D setup workflow that combines blueprint-based block generation, real measurements, AI accuracy verification, manual correction, and specialized seating, GA, table-plan, and parking configuration — producing a verified and reusable venue layout foundation in one system.”
